# TimeSyncBot 🎓

Современный многофункциональный Telegram-бот для студентов и преподавателей ВятГУ.
Помогает отслеживать учебное расписание, искать пары преподавателей, находить свободные аудитории, выявлять общее свободное время между группами, а также автоматически публиковать и закреплять расписание в группах и топиках Telegram.

---

## 🌟 Возможности

### 🎓 Студентам
- 📅 **Расписание на сегодня, завтра и неделю** с точным временем пар, аудиториями и преподавателями.
- 🔮 **Умный прогноз расписания**: чёткая индикация актуального статуса (🔴 *Официальное расписание* по утверждённым PDF / 🔮 *Прогноз расписания* по базовой сетке при отсутствии новых файлов).
- ⭐ **Избранные группы**: свободный просмотр расписания любых групп университета и добавление их в быстрый доступ.
- 📄 **Постраничный выбор групп**: удобная навигация по каталогу всех институтов и групп ВятГУ.
- 🔎 **Свободные аудитории**: быстрый поиск незанятых кабинетов в конкретном корпусе и на конкретной паре.
- 👥 **Поиск общего свободного времени (`/meet`)**: выявление общих окон и свободных пар между несколькими группами для организации встреч.
- ⚙️ **Гибкие персональные настройки**: включение/выключение отображения преподавателей, типов занятий и номеров аудиторий.

### 👨‍🏫 Преподавателям
- 🔍 **Поиск по фамилии**: быстрый поиск любого преподавателя ВятГУ без необходимости выбирать кафедру.
- 🏛️ **Навигация по институтам и кафедрам**: структурированный каталог преподавателей.
- 📆 **Расписание преподавателя**: просмотр занятий на сегодня, завтра и всю неделю.

### 👥 Telegram-группам и супергруппам
- 🤖 **Работа в группах**: добавьте бота в студенческий чат и привяжите группу одной командой (`/setgroup ИВТб-1302`).
- ⏰ **Автоматическая утренняя/вечерняя рассылка**: доставка расписания в заданное время (`06:30`, `07:00`, `07:30`, `08:00`, `19:00`, `20:00`, `21:00`).
- 💬 **Поддержка топиков супергрупп (`/settopic`)**: автоматическая отправка расписания в выбранную тему форума.
- 📌 **Закрепление сообщений**: автоматическое закрепление утренней рассылки или ответов на `/today` в чате / топике.
- 🔒 **Строгая защита прав**: менять настройки чата и привязывать группы могут **только администраторы**.
- ⚡ **Быстрые команды для студентов**: `/today`, `/tomorrow`, `/week`.

### 📱 Android Widget REST API
- 🌐 Встроенный быстрый HTTP REST API сервер (на порту 8000) для интеграции с виджетами рабочего стола Android:
  - `GET /api/health` — проверка работоспособности бота и БД.
  - `GET /api/groups/search?q=ИВТ` — автодополнение групп.
  - `GET /api/schedule/{group_name}?date=YYYY-MM-DD` — расписание группы в формате JSON.

## 🛠️ Стек технологий

- **Язык**: Python 3.11+
- **Пакетный менеджер**: [uv](https://github.com/astral-sh/uv) (быстрый, воспроизводимый с `uv.lock`)
- **Telegram Bot Framework**: [aiogram 3.x](https://github.com/aiogram/aiogram)
- **База данных**: SQLite (с SQLAlchemy 2.0 / SQLModel асинхронно через `aiosqlite`)
- **Парсинг**: `PyMuPDF` (fitz), `pdfplumber`, `selectolax`, `BeautifulSoup4`, `aiohttp`
- **Планировщик**: `APScheduler`
- **Контейнеризация**: Docker, Docker Compose

## 🚀 Быстрый запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/smileyfaceskobochka/TimeSyncBot.git
cd TimeSyncBot
```

### 2. Конфигурация окружения

Скопируйте пример файла конфигурации:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Токен бота из @BotFather (обязательно)
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Telegram ID администраторов через запятую (обязательно)
ADMIN_IDS=123456789

# Часовой пояс (по умолчанию Europe/Moscow)
TZ=Europe/Moscow
```

---

### Вариант А: Запуск в Docker Compose (Рекомендуется для продакшена)

Сборка и запуск контейнера в фоновом режиме:

```bash
docker compose up -d --build
```

Просмотр логов:
```bash
docker compose logs -f timesyncbot
```

Остановка:
```bash
docker compose down
```

---

### Вариант Б: Локальный запуск через `uv`

1. Установите [uv](https://github.com/astral-sh/uv) (если ещё не установлен):
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```
2. Синхронизируйте виртуальное окружение:
   ```bash
   uv sync
   ```
3. Запустите бота:
   ```bash
   uv run python main.py
   ```

## 📋 Команды бота

### В личных сообщениях:
| Команда | Описание |
|---|---|
| `/start` | Главное меню и выбор группы |
| `/help` | Справка по всем возможностям |
| `/meet <Группа1> <Группа2> [Дата]` | Поиск общего свободного времени между группами |
| `/teacher` | Меню поиска преподавателей |

### В групповых чатах:
| Команда | Кто может вызывать | Описание |
|---|---|---|
| `/today` (или `/сегодня`, `/пары`) | Все участники | Расписание группы на сегодня |
| `/tomorrow` (или `/завтра`) | Все участники | Расписание группы на завтра |
| `/week` (или `/неделя`) | Все участники | Расписание на текущую неделю |
| `/setgroup <название>` | Только администраторы | Привязать учебную группу к чату |
| `/settopic` / `/settopic off` | Только администраторы | Привязать/сбросить тему супергруппы для рассылки |
| `/chat_settings` | Только администраторы | Интерактивное меню настроек авторассылки и закреплений |

### Для администраторов бота (из `ADMIN_IDS`):
| Команда | Описание |
|---|---|
| `/admin` | Админ-панель управления |
| `/health` | Проверка статуса компонентов бота и базы данных |
| `/parse` | Принудительный запуск обновления расписания |
| `/stop_bot` | Безопасная остановка процесса бота (SIGTERM) |

## 🛡️ Безопасность и надёжность

- **Graceful Shutdown**: обработка `SIGTERM` и `SIGINT` с корректной остановкой планировщика задач и закрытием соединений aiohttp.
- **Изоляция данных**: директории `data/` и `logs/` сохраняются через Docker Volumes и не стираются при перезапуске.
- **Самовосстановление**: при недоступности внешнего сайта ВятГУ бот стартует на локальном кэше и повторяет попытки в фоне.
- **Автоматическая миграция БД**: SQLite таблицы безопасно расширяются новыми колонками без потери существующих данных пользователей.
